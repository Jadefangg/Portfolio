# Portfolio Website

A modern, interactive portfolio website built with React and GSAP, featuring parallax scrolling effects, 3D carousel, and responsive design.

## 🚀 Features

- Animated parallax scrolling mountain scene
- Interactive 3D project carousel
- Responsive design for all devices
- Custom loading animation
- Dynamic star field background
- Sliding technology logo showcase
- Contact form with email integration
- SVG animations and transitions

## 🛠️ Technologies

- React.js
- GSAP (GreenSock Animation Platform)
- CSS3 with custom animations
- SVG graphics
- Responsive design principles
